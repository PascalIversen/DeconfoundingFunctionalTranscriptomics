# Fig 4a: Self- and functional-partner recovery (DepMap)

Panel **a** of Figure 4: for each knockout target, how highly the deconfounded
attributions rank the target's own gene (self) and its functional partners
(STRING one-hop ≥700, CORUM complex co-members) versus size-matched random gene
sets, as ΔAUROC vs Marginal (paired Wilcoxon, BH-corrected).

## Recompute from predictions

```bash
python compute_self_recovery.py       # -> data/selfrank_newpanel*.csv
python compute_partner_recovery.py    # -> data/panel_newpanel_depmap*.csv
python make_panelA.py                 # standalone panel (paper uses the joined Fig 4)
```

Both rank genes by each method's global importance `a_g = mean_i|SHAP|` from
`../results/depmap_seedavg_preds/*.npz` (`imp_<method>`, no per-cell SHAP needed).
`recovery_utils.py` holds the shared helpers (BH-intersection, STRING/CORUM/co-ess
partner sets, AUROC).

## Inputs

- **Importances:** `../results/depmap_seedavg_preds/` (seed-averaged; regenerated by
  `../training/aggregate_seed_importances.py`).
- **BH-intersection:** `../results/depmap_within_tissue_pvals.csv` (marginal ∩
  residualized pass within-tissue-r BH-FDR → n=144 self, 118 STRING, 26 CORUM).
- **STRING v12:** `../data/partners/string/{info,links}.v12.0.txt.gz` (public
  download, ~81 MB, git-ignored, see `../data/partners/README.md`).
- **CORUM:** `../data/partners/CORUM.gmt`.
- **Co-essentiality:** DepMap `CRISPRGeneEffect.csv` (from the raw-data bundle).

## Reproduction notes

The columns the paper figure uses, **self, STRING, CORUM, and the RANDOM control -
reproduce exactly**. The extra `coessG`/`coessW` co-essentiality columns are stored
for reference but are **not shown in Fig 4**; they are computed from the full DepMap
Chronos matrix and therefore track the bundled DepMap release rather than being
release-independent.
